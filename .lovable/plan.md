# Arvind Backend Engineering Portfolio

## Goal
Build a complete, responsive single-page portfolio for Siram Chiru Arvind’s IIIT Sri City R&D internship application. The result will feel restrained, technical, academic, and honest—focused on backend engineering potential rather than marketing claims.

## What I’ll build
- Sticky desktop navigation and accessible mobile menu with smooth section links
- Hero introducing Arvind’s Java and Spring Boot focus, plus a lightweight backend architecture diagram
- About, categorized technical skills, backend engineering approach, and three clearly labeled project placeholders
- Education, R&D internship alignment, current learning areas, and systems Arvind wants to build
- Resume callout using `/resume.pdf`, contact links, GitHub link, LinkedIn link, and a minimal footer
- Centralized portfolio data for easy future edits
- Subtle section entrance and card interactions with reduced-motion support
- Route-specific title, description, Open Graph metadata, canonical URL, and accessible semantic structure

## Visual direction
- Warm off-white canvas, near-black typography, cool gray supporting text, and a restrained deep teal accent
- Strong editorial typography with a slightly academic feel
- Fine borders, compact labels, structured grids, and engineering-diagram details
- No stock imagery, fake terminal, glass effects, skill percentages, or fabricated claims

## Technical details
- Use the existing React, TypeScript, Tailwind CSS, Lucide, and TanStack setup
- Add focused portfolio components and a single typed configuration module
- Keep all colors, typography, shadows, and motion values in the global design system
- Verify desktop and mobile layouts, navigation/menu behavior, links, metadata, and current build health
